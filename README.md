# Pi Agent Access

面向 VoiceOver 用户的中文 macOS 智能体桌面应用。基于 Pi Agent Desktop 和 Pi Web，在上游内核上维护无障碍、电脑操作、上下文控制、记忆和设置管理能力。本项目是独立社区修改版，不是上游或 OpenAI 的官方产品。

首个发行版为 1.0.0，目前发布 Apple Silicon（arm64）安装包。可从本仓库的 Releases 页面下载 DMG；安装包包含桌面应用、Node 运行环境、记忆与上下文功能，以及经维护的 LCU 开源适配层。普通聊天不需要安装开发工具或使用终端。

## 主要改进

中文界面、可理解的控件名称、合理的屏幕阅读顺序、逐级菜单与返回焦点。历史会话支持旁白激活、管理、重命名、批量删除、侧栏收起及常用快捷键。消息操作包含复制、朗读、删除、恢复与回滚，支持添加附件及可访问的产物链接。

“能力与上下文”分别管理基础指令、项目说明、记忆、文件与终端、插件、技能、MCP、模型与设置。关闭的能力不会作为当前选定工具继续暴露。技能索引与正文按需加载；固定的会话前缀尽量保持顺序稳定。会话中途调整能力仍可能改变缓存前缀，界面提供代价说明。并非所有提供商都支持准确的本地分词计数。

独立本地记忆支持查看、编辑、创建与检索。首版使用关键词、日期及关联词检索，没有把关联词搜索冒充为向量语义检索。记忆、模型配置、聊天和凭证均保存在用户自己电脑上，发行包不包含开发者的任何这些数据。

模型与设置能力默认关闭；启用后可通过内部工具管理模型、提供商及相关智能体资源。独立权限页面提供只读、询问批准和完全访问。模型配置保存前检查协议与端点一致性，并提供无需模型连接即可使用的配置回退入口。

Computer Use 沿用 LCU 0.12.0 的维护版 v14，保留桌面输入、状态与图像反馈修复，启用浏览器接口。普通应用和网页访问可在首次设置时明确启用默认允许，仍尊重应用权限模式。不会自动回答未知敏感表单或修改 macOS 隐私权限。

## 安装与首次使用

打开下载的 DMG，将 Pi Agent Access 放入“应用程序”，再打开应用。它使用独立配置目录，不覆盖原版 Pi。首次请在设置中的模型页面连接您自己的提供商，或使用支持的账号授权；安装包没有内置付费账号、API 密钥或大型模型。

电脑操作需要本机安装官方 ChatGPT 桌面应用。它提供自己的 Computer Use 运行时，LCU 从本机安装中读取，并不会绕过系统权限。进入设置、常规中的“电脑操作首次设置”，点击“启用电脑操作”，随后按 macOS 提示完成无障碍、录屏及必要的应用控制授权。Chrome 还需要安装并启用官方 ChatGPT 浏览器扩展，页面内提供按钮。此设置不需要输入终端命令。

独立数据目录位于用户的“资源库/Application Support/Pi Agent Access”，聊天、模型配置与记忆在其中的 agent 目录。原版 Pi 的数据不会自动复制进来。

本次发布采用本地临时签名，未经过 Apple Developer ID 公证。macOS 可能要求在“系统设置、隐私与安全性”中确认打开；不要关闭系统安全保护，也不要向陌生人提供系统密码。首次系统隐私授权必须由用户本人确认，安装包不能预先替另一台电脑授权。

## 验证范围与反馈

本版继承已经由 VoiceOver 用户手动验收的中文界面和交互功能。维护记录包括桌面与浏览器真实状态回读、多会话缓存恢复、权限策略回归等。它不等于所有电脑、所有应用、所有模型均已验证；本地缓存的 128 GiB 部署参数属于开发机运维经验，不会向其他用户安装这些模型或改动其推理服务。

Safari 可通过原生桌面接口使用；浏览器专用接口当前实证为已安装官方扩展的 Chrome。其他浏览器是否支持取决于上游及本机连接条件。模型自身选错目标或编造函数，与底层工具错误分别记录。

欢迎通过 Issues 反馈，说明系统版本、芯片、模型、期望结果和实际结果；请勿提交 API 密钥、聊天隐私、截图中的私人信息或完整凭证文件。

## 开发构建

开发需要 Node 22.19 或更高版本、npm、Rust/Tauri 与 macOS 构建工具。常规检查为 npm test、npm run lint 与 TypeScript 检查；桌面资源使用 npm run desktop:prepare。macOS 应使用独立、可分发的 Node 22 二进制，不能把依赖本机 Homebrew 动态库的 Node 当作独立运行环境。

构建时会把开源 LCU 薄发行组件和维护模板装入应用资源，首次设置只复用本机官方 ChatGPT，不下载或嵌入 OpenAI 运行时。GitHub 自动更新未启用签名发布，1.0.0 请从 Releases 手动更新。

发布包可通过 scripts/package-access-macos.py 组装与本地签名，scripts/verify-access-package.mjs 对产物执行隔离配置检查。Node 外部链接在资源中使用占位文件，首次安装时恢复为 LCU 原始清单中的链接，再由上游安装器校验；不会打包外部 ChatGPT。
