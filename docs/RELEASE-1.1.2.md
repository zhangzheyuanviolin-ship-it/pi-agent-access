# Pi Agent Access 1.1.2

修复支持视频的模型在普通新对话、历史对话、项目切换、纯聊天和能力配置会话中未自动加载视频输入的问题。视频能力随当前模型自动生效，无需用户单独打开；桌面与移动网页使用同一后端。直接读取本机视频文件也进入当前模型的原生视频接口，避免把二进制作为文字写入上下文；不自动调用云端视频技能或更换模型。

保留现有本地与云端模型、中文无障碍界面、文件收发、能力与上下文、手动压缩及原有历史。加入重复大网页观察的无损差分输出，减少浏览器操作中反复加入大段相同页面结构；初次完整观察仍保留。普通后续消息不重写旧消息或增加动态时间前缀。

本机实际验收包含约200秒、31.2MB MP4的本地视觉调用、桌面和移动布局上传、read读取视频、纯聊天、关闭一般文件工具后的用户指定视频、模型切换及后续上下文。23项定向回归通过，TypeScript、生产构建和安装包启动检查另外保留记录。识别接口可达不等于模型内容判断必定正确：实测保留了数量与时间轴错误。具体模型的速度、视频采样密度及输入容量取决于后端，不承诺任意视频都逐帧准确识别。

仅对已验证的模型提供视频入口；未验证模型不会冒充支持。当前oMLX路径整段提交MP4，由引擎处理时序采样；限制和取消会明确反馈，不把无响应或错误当成功。保护原模型及用户数据，不自动安装或下载权重，不替用户更改默认模型。

macOS安装包为Apple Silicon arm64，自签名，未进行Apple公证。电脑操作仍需要系统辅助功能、录屏等用户授权和兼容的原生组件；本版没有把闭源组件重新包装为完全自主驱动。源代码和移动网页修复已一并更新。
