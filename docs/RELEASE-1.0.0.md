# Pi Agent Access 1.0.0

首个稳定发行版，面向使用 VoiceOver 的中文 macOS 用户。安装包仅适用于 Apple Silicon（arm64）。这是独立社区修改版，不是 Pi 上游或 OpenAI 的官方产品。

## 本版包含

中文无障碍界面、分层设置与焦点恢复；可访问的历史会话与批量管理；消息复制、朗读、删除、恢复及回滚；附件与产物链接；多提供商模型配置和账号授权入口。

八类能力与上下文开关、按需技能索引、会话前缀变更提示、本地记忆创建与检索、模型与设置内部工具、独立权限管理及离线配置回退。

Node 22.23.3、必要的应用依赖，以及 LCU 0.12.0 维护版 v14 的开源适配组件。无需另装 Node 或手动复制插件。

## 首次安装

打开 DMG，把 Pi Agent Access 放入应用程序后打开。应用采用独立标识与独立用户数据目录，不替换原版 Pi。请配置自己的模型提供商或完成账号授权；发行包没有任何开发者密钥、聊天记录或大型模型。

电脑操作还需要用户从官方渠道安装兼容的 ChatGPT 桌面应用。应用设置、常规中提供“电脑操作首次设置”，可启用普通访问策略并配置浏览器连接。Chrome 还需官方扩展；macOS 无障碍、录屏及必要的应用控制权限必须由使用者首次确认。OpenAI 的专有应用、运行时和浏览器扩展没有随包再分发。

本版使用本地临时签名，尚无 Apple Developer ID 公证。macOS 可能需要使用者在“隐私与安全性”确认打开。不要关闭系统安全保护。建议在 macOS 14 或更新系统使用；完整电脑操作还取决于官方 ChatGPT 的系统要求。

## 验证

源代码完整测试 3100 项通过，TypeScript 检查、ESLint 检查、桌面生产构建和 arm64 Rust 构建通过。安装包通过递归签名验证，LCU 4504 个清单条目逐项核对；外部 Node 链接采用安装时恢复的清单占位，不包含 OpenAI 运行时。

使用独立临时用户配置验证了 LCU 首次安装、扩展登记、创建智能体会话、设置状态读取，以及未授权设置请求拒绝。打包后代码沙箱和 Bedrock 依赖加载检查通过。在本机实际打开发布包，旁白可读取中文设置与“电脑操作组件已准备”反馈。

这些验证不能替代另一台电脑的权限和模型实测，也不表示所有模型、浏览器和应用均能零失败运行。记忆使用关键词、日期与关联词检索，本版不包含向量检索模型。自动更新尚未启用签名发行，请从本仓库 Releases 下载更新。
