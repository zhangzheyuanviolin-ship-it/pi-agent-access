# Pi Agent Access 1.1.0 中文无障碍稳定版

本版本同步发布桌面客户端与同一套响应式手机网页源代码。新增本地与云端视频分析接口：可让已配置支持视频的模型通过 `video_analyze` 分析 MP4；已验证 oMLX Qwen 27B 与 MiniMax M3.1 Flash 的原生 video_url 路径。模型、引擎和付费云端凭证不随安装包分发，也不会自动安装或自动调用付费模型。

视频工具只在用户启用文件能力且当前模型有视频路由时提供，沿用当前模型认证，不静默切换到云端；支持取消、等待心跳及明确错误。上传文件本身与视频分析预算分开：单次原生分析当前上限80MiB，不会自动截短长视频；大视频自动分段未实现。原生模型也可能误判数量等细节。

完善稳定的上下文前缀管理：附件路径只附在下一条新用户消息，不回写历史；记忆与能力采用会话固定快照，只有用户明确应用变更才更新。补齐手动压缩入口、终端运行状态反馈、手机文件传输与结果下载、共享桌面/手机会话状态。这些措施不能保证所有模型、跨后端淘汰或任意长度空闲均命中缓存。

修复卸载本地后端后，已打开的模型选择器将旧条目与刷新目录合并、导致已卸载模型继续出现的问题。当前统一本地提供商使用最新配置作为权威清单，不改变云端模型、默认模型或旧会话内容。

macOS arm64安装包为本地临时签名，未经Apple Developer ID公证；不会自动安装到本机或改变现有完全磁盘访问权限。系统隐私授权仍须用户本人通过系统设置完成。现有用户的数据、密钥、个人记忆、聊天历史、模型权重、网络配置和本机绝对路径不随发布包分发。

本地/云端、桌面宽度/手机宽度上传与自主读取文件的六种视频路径已在本机浏览器和真实模型接口验证；手机宽度验证不是亲自操作iPhone的跨网验收。

构建与测试结果、附件校验值随本次Release单独提供。源码包含手机网页，不另维护第二份前端。部署与视频路由见 docs/video-and-mobile-deployment.md。
