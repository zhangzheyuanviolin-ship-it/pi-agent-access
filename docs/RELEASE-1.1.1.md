# Pi Agent Access 1.1.1

修复特定固定工具配置会话中，状态轮询重置工具列表的问题。当前模型不支持的视频工具不再被能力恢复逻辑重新加入；运行中查询状态不再修改工具声明，避免工具循环和续聊产生无必要的前缀失效。

保留1.1.0的视频分析接口、手机网页、文件收发、手动压缩及中文无障碍功能。视频工具仍只向已配置兼容能力的模型提供，不会为了分析而偷偷切换供应商。

本机模型网关另外修复闲置服务卸载权重后仍保留内存池的问题，补丁位于docs/patches/model-gateway-idle-memory.patch。此网关属于独立部署环境；桌面安装包不会擅自管理用户其他模型进程。仅正常退出身份、启动时间和配方均已核实且没有工作中的引擎；当前使用中的已加载模型直接复用。

应用全量3123项测试及类型检查通过。所有七个已部署后端均实际完成文字、多轮暗号、文件写入再读取和续聊缓存验证；六个声明支持图片的后端完成真实图片输入，oMLX路径完成实际视频工具调用。桌面及手机布局另行验证，详细范围见本机验收报告，不把本机模拟布局冒充真实iPhone跨网测试，也不把短样本冒充长期空闲可靠性保证。

Apple Silicon安装包采用临时签名，尚未进行Apple Developer ID公证。个人模型、凭证、历史和记忆不包含在公开源码或安装包中。


已核实的上游限制：MLTF 0.1.2允许含图会话在RAM中复用，但原生SSD协调器明确跳过含图请求的查找与发布。因此含图历史在进程重启或切换模型后仍会重新预填充；纯文字SSD恢复不受这一限制。此项需要上游持久层协议支持，不属于已修复能力，也没有通过移除安全判断伪造命中。依据：https://github.com/DT-HJ/my-little-trie-forge/blob/873d5574d903f5c1685e286c9cd59b79475a49f6/runtime/engine/RuntimeResources.mm#L378
