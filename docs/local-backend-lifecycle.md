# 本地模型服务的内存生命周期

GPU有线内存上限是分配上限，不增加统一内存容量。专家驻留预算也不是整台机器的全部内存需求；操作系统、辅助功能、客户端、KV和图像缓冲另需余量。

卸载权重后，部分推理服务仍保留MLX内存池。需要加载另一个大型模型时，应先通过原生状态接口确认没有活动、等待和缓存写入，正常卸载权重，再仅退出正面识别的闲置服务进程。保留磁盘前缀缓存及权重，不终止旁白、系统音频或网络组件。

本项目本机独立模型网关补丁见patches/model-gateway-idle-memory.patch。oMLX会改变进程标题，因此该网关对自己启动的服务保存私密所有权凭据，核对PID、UID、内核启动时间和启动配方哈希；不按名称匹配杀进程。已加载的当前模型直接复用。不能绕过引擎内存预检来伪造加载成功。

若其他任务确实消耗了设备必需余量，应保留准确错误并等待资源释放；不能保证物理内存不足时仍可加载。独占性能测试配置与多应用日常配置需分开记录，不应悄悄改低预算后仍声称同配置。
