# Pi Agent Access 1.1.4

本版对应2026年11月3日用户本人在桌面及iPhone远程实际验收的稳定功能：DeepSeek V4.1正常对话与工具；本地Qwen3.8-27B oQ8e FP16 MTP原生视频时间轴分析、电脑与浏览器操作、续聊前缀缓存。保留全部其他本地和云端提供商。

原生视频接口自动随当前支持型号提供，无需另行开启工具，不按会话类型区分；同时保留云端原生视频路径。文件上传、下载、手动上下文压缩、全局记忆默认开启及项目记忆默认关闭延续现有行为。普通消息及附件通知不改写历史前缀。

稳定发布检查清单更新为目前七个本地后端。既有DeepSeek加载准入和保护音频的内存检查继续保留，不通过降低预算或绕过资源检查来加载。当前安装包不包含模型权重、私人模型目录、API密钥或账户状态；新电脑仍需独立配置其模型与权限。

实测范围不等于所有视频均能正确识别。MLTF含图历史的SSD恢复仍有上游限制；电脑操作依赖现有LCU组件及相应系统授权。安装包为Apple Silicon、ad-hoc签名，未经Apple公证。
